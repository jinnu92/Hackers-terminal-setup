📦 Modular Architecture (`lib/` Breakdown)

Maintainable, clean decomposition. Each domain lives in its own module under lib/, and a single compiler script bundle.sh builds the single-file curl-pipeable distribution.

Directory Structure: 
Hackers-terminal-setup/
├── ter.sh                # Universal entrypoint (sources lib/ or runs bundled)
├── bundle.sh             # Compiler: joins lib/*.sh into standalone curl distribution
├── terminal_preview.html # Interactive visual showcase and profile builder
├── lib/
│   ├── common.sh         # Colors, logging, banners, OS detection
│   ├── pkg_mgr.sh        # Brew, apt, dnf, pacman unified wrapper
│   ├── helpers.sh        # Go, pipx, npm global prefix isolation
│   ├── preflight.sh      # Dependencies, disk checks, root safety
│   ├── fonts.sh          # Modern Nerd Fonts multi-distro installer
│   ├── dev.sh            # Node.js LTS, Claude Code, VS Code CLI
│   ├── terminals.sh      # Ghostty, WezTerm, Kitty + aesthetic configs
│   ├── shell_tools.sh    # Atuin, direnv, uv, btop, yazi, delta, Starship
│   ├── ad_pivoting.sh    # Ligolo-ng, Chisel, NetExec, BloodHound, Certipy
│   ├── web_api.sh        # Schemathesis, Kiterunner, Caido, Arjun, FFUF
│   ├── cloud_devsec.sh   # Trivy, Syft, Grype, Checkov, Kube-hunter
│   ├── mobile_re.sh      # Jadx, Apktool (DEX/APK decompilation & analysis)
│   ├── pentest.sh        # Core offensive security auditing suite
│   ├── bugbounty.sh      # Web recon, discovery & nuclei automation
│   ├── cloud.sh          # Cloud & container security testing tools
│   ├── ai_mcp.sh         # Preconfigured safe MCP suite & Claude config
│   ├── workflow.sh       # Tmux, aliases, custom helper functions
│   ├── dashboard.sh      # Fastfetch & Tactical Security Welcome Cockpit
│   ├── doctor.sh         # sec_doctor automated health dashboard
│   ├── configs.sh        # Dotfile generators (.zshrc, .tmux.conf, configs)
│   └── menu.sh           # Interactive ASCII menu & CLI argument parser
Key Architectural Principles:
  • ✓ Dual-Mode Execution
    Edit any file in lib/*.sh and run ./ter.sh directly to test changes immediately. Run ./bundle.sh to compile the single-file distribution.
  • ✓ Clean Domain Isolation
    Every domain (Active Directory, Web APIs, Containers, Mobile, AI) has its own module, dependencies, and doctor checks.
  • ✓ Sub-15ms Terminal Startup
    The modernized welcome cockpit avoids synchronous web queries and provides immediate, actionable telemetry at launch.
